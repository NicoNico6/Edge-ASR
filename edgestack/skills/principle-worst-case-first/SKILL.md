# 最坏输入先行

先测包络边缘，再测均值情形：最长输入、最难场景、静音与噪声、混合语言、远场、热降频后的时钟、内存峰值、并发、冷启动。

**为什么：** 均值好不等于可发货。端侧的失败常发生在长输入（缓存线性增长撑爆内存）、热降频（时延翻倍）、少见输入（循环、空输出）上。这些在均值里几乎看不见。

**做法：**
- 测试集里固定一组最坏切片，单独报指标和失败计数。
- 时延报 p50、p95、p99 和最大值，内存报峰值而不是平均。
- 长跑之后再测一次，确认热稳态下仍然达标。
- 能从物理量推出上限的（例如解码最大长度由输入时长决定），按物理量设，不拍常数。

**边界：** 区别于 **principle-failure-counts-beside-means**（怎么报）和 **principle-three-axes**（验收什么）。

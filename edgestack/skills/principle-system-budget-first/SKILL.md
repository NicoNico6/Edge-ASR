# 系统预算先分

先分系统预算，再定单个模型。把内存、算力时间片、带宽、功耗按场景分给每个模型，算上它们同时运行的最坏情况。每个模型的预算卡从系统预算推出来，不各自独立定。

**为什么：** 每个模型单独达标，放到一起可能内存爆掉、时延链超标、常驻模型抢占了带宽。系统的瓶颈常在并发和切换上，不在任何一个模型里。

**做法：**
- 列场景和每个场景同时活跃的模型（例如唤醒常驻，识别与合成交替，LLM 按需）。按最坏并发算峰值内存和带宽。
- 画端到端时延链（唤醒 → 识别首字 → LLM 首 token → 合成首包），给每段分时延预算。
- 找能共享的部分：编码器、词表或分词器、声码器、特征提取、内存池。
- 决定常驻和按需加载，算加载时间和对时延链的影响。
- 系统预算写进预算卡，每个模型一节。

**边界：** 区别于 **principle-budget-before-model**（单个模型）。

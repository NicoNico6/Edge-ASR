# 看住算力预算

GPU 时、板时、排队资历都是预算。一次只改一个变量，预设中止判据，并行臂互不共享输出，空闲资源要能被发现，不为对比而对比。

**为什么：** 算力浪费常来自三处：没有中止判据的实验跑完才发现无效，空闲的卡没人发现，为了凑对比表而跑价值低的配置。

**做法：**
- 每个实验写明目的、变量、预计时长、中止判据（例如前 N 步指标没有低于某值就停）。
- 每题或每批落盘，支持分段运行和拼接，作业被杀不丢结果。
- 用 `scripts/idle_gpus.sh` 一类的检查定期发现空闲资源，空闲时报告。
- 资源集中在最有价值的方法上做验证，对比实验只跑能改变决定的那些。
- 并行臂各自独立的输出目录、设备、分支。

**边界：** 区别于 **principle-guard-the-context-window**（agent 的上下文预算）。

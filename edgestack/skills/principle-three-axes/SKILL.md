# 三轴验收

三轴同时过线才是可发货点：质量（精度或感知）、成本（时间、空间、能量，固定口径）、稳定性（帧间抖动、噪声敏感度、长跑漂移）。

**为什么：** 静态精度更好的配置可能抖动更大，更快的配置可能长跑后漂移。精度和稳定性常常结构性冲突。只看一个轴选部署点，到产品里会出问题。

**做法：**
- 每个候选配置在三轴上都有数字，缺一轴不能当候选。
- 稳定性的可接受代价写进规格（例如抖动率上限、噪声敏感度上限），不靠事后判断。
- 用 **stability** skill 测稳定性。
- 选择权在两个轴之间无法兼得时，把选项和代价列清楚交给负责人决定。

**边界：** 区别于 **principle-perception-decides**（感知类质量怎么判）和 **principle-worst-case-first**（测哪些输入）。

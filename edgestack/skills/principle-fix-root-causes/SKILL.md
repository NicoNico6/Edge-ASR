# 修根因

先复现，再二分，问为什么直到根因。只修症状的补丁不交付。

**为什么：** 症状级修复会掩盖问题，让同一根因在别处再出现。端侧问题尤其常见于预处理不一致、对齐假设、静默的硬件错误。

**做法：**
- 在相同的表面上复现：同一硬件、同一输入、同一配置。复现不了先补齐条件或加探针。
- 每次取能排除最多可能性的切分点，拿运行时证据排除假设。
- 每一行交付的修改都能对应到证据。「可能有帮助」的补丁是假设，不是修复。
- 证据推翻假设时，回退它引出的改动。

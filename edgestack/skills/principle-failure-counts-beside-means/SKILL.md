# 失败计数单列

在均值旁边单列失败的条数：空输出、重复循环、解析失败、截断、超时、崩溃、OOM、人数或类别估错。

**为什么：** 均值会把塌缩藏起来。少数样本的灾难性失败可以被大量正常样本平均掉，而这些失败在产品里最显眼。

**做法：**
- 评测脚本输出失败计数，按类型分列。没有计数的脚本先补上。
- 按长度、场景、语言分档报指标，看是否在某一档单调变差（常见于截断和缓存）。
- 工程故障（崩溃、超时）和模型错误分开记。对比别人的方法时，工程故障可以剔除并说明，不算作模型答错。
- 失败样本抽几条原样贴进总账，作为证据。

**边界：** 区别于 **principle-worst-case-first**（测什么）和 **principle-three-axes**（验收什么）。

# Stability

## 指标

- **帧间抖动**：静态或缓变场景里相邻帧输出的变化，例如变化超过阈值的像素或 token 比例。
- **噪声敏感度**：输入加小噪声（固定 σ、独立 seed）后输出变化的比例，是抖动的代理。
- **长跑漂移**：长时间运行后指标、内存、时延的变化。
- **热稳态**：持续负载到温度和时钟稳定后，再测时延和质量。
- **流式一致性**：临时结果和最终结果的差异、修正次数。

## 协议

1. 固定测试序列（真实采集的连续输入，不只用单帧数据集）。
2. 每个指标写明定义和阈值，进预算卡。
3. 对比配置时同一序列、同一 seed、同一显示方式（**side-by-side** skill）。
4. 长跑至少到热稳态，记录时钟、温度、内存曲线。
5. 精度和稳定冲突时，两个数都报，不只报好看的那个。

## 输出

指标表（带口径）、可视化、和规格的对比、精度与稳定冲突的说明。

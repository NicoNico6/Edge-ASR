# 以感知为准

自动指标是参考，人的感知是判决。交付里放同样本、同种子、同设置并排的可感知产物，人的判断记进总账。

**为什么：** 自动指标和人的感受相反的情况经常出现：字错率更低但音色更差，静态误差更低但画面闪烁更明显。只看指标会选错。

**做法：**
- 用 **side-by-side** skill 做并排产物：同一条输入、同一个种子、同一份产品设置，参考在前，候选按版本排。
- 固定显示条件（固定色标、固定音量、固定采样设置），否则差异来自显示而不是模型。
- 记录谁在什么时候听或看了哪些样本，给出了什么判断。
- 自动指标和感知冲突时，写下冲突，以感知为准，并考虑尺子是否需要加一项。

**边界：** 区别于 **principle-three-axes**（三个轴都要过）。

# 归因到层

把差距拆到栈的某一层：预处理、模型、计算图变换、kernel、运行时调度、存储、硬件、解码与后处理。每次只换一层来二分，始终保留一条浮点参考路径。

**为什么：** 设备上的质量下降可能来自量化、某个 kernel、一次图变换、预处理与训练不一致、解码配置不同。不归因就修，常常修错层，还会把两个错误互相抵消的状态当成修好了。

**做法：**
- 列出参考路径和设备路径之间每一层的差异。
- 一次只把一层换成参考实现，看差距是否消失。
- 时延差距按阶段拆成表，每行一个阶段，加一行「未归类」。未归类超过 10% 先补剖析。
- 浮点参考路径保留到交付之后，用于二分和回退。

**边界：** 区别于 **principle-parity-ladder**（逐级对齐数值的方法）和 **principle-fix-root-causes**（调试的一般纪律）。

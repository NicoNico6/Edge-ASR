# 先造杠杆

造一个工具来做或证明这件事：脚本、扫描器、生成器、对拍器、日志解析器。工具是审阅者能重跑的证据。

**为什么：** 手工做的工作只能靠再做一遍来复核。工具每次以同样方式运行，重跑免费，把「相信我」变成「运行这个」。

**做法：**
- 先手工做一个单元学会步骤，再造工具，用它重跑这个单元并和手工结果对比。
- 工具要能安全重跑（幂等）。
- 派子 agent 扇出时，把配方、验证标准、禁区写成一份它们都读的文件。
- 用到这条原则就应该在产出里有一个脚本或工具。没有就是没用。

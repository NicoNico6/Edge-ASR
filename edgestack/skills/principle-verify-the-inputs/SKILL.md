# 核实输入

用到的输入都要自己核实过。数据核到 repo、分片、字节数、许可和重叠；对手方法在同框架、同硬件上复现一个锚点；教师输出抽样检查；引用来自真实的文献库，从不生成。

**为什么：** 数据集的子集命名、划分重叠、许可限制经常和描述不符。论文声称的数字可能无法复现。生成的引用可能不存在。基于未核实的输入做出的结论会在最后一刻崩掉。

**做法：**
- 用 **verify-inputs** skill 的清单。
- 复现对手方法先选最快的数据集和重合的模型，定义通过标准（例如论文数字正负 3 个点），通过之前不铺开。
- 先证明「管线无罪」：用同一套模板、解析和评分复现论文里的基线行。
- 受限数据（不得公开的测试集、密钥）不贴进对话，不上传公开位置。

**边界：** 区别于 **principle-cite-precedent**（方法要有来源）。

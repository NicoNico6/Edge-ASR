# 最便宜的判别实验

设计能把两个解释分开的最便宜的实验，先跑它。判一条路线死刑要有机制证据，不按「试过一次不行」算。

**为什么：** 争论和猜测消耗的时间常比一个小实验多。很多路线被放弃是因为第一次实现有 bug 或配置不对，而不是机制不行。

**做法：**
- 写下两个假设各自预测的可观测差异（数值、签名、分布），挑能区分它们的最小切片。
- 把每个猜想做成命令行开关，结果文件名带上开关，方便对照。
- 用结构性签名快速裁决：例如成本恒定、某一档单调变差、某个计数为零。
- 宣布失败时写明机制：为什么这条路线在当前约束下不行。只有「效果不好」不算机制。

**边界：** 区别于 **principle-fix-root-causes**（调试一个已知问题）和 **principle-never-block-on-the-human**（不问能用实验回答的问题）。

# 配置即复现

每次运行都能由 commit、配置、数据版本、设备、固件或驱动版本、seed 重建。数值依赖调度、线程或缓存状态时，提供确定性开关并在口径里写明是否开启。

**为什么：** 无法重建的结果无法复核，也无法在出问题时二分。多线程归约、推测解码、缓存状态都可能让同一输入的输出不同。

**做法：**
- 结果文件名或总账行包含配置 hash 和 commit。
- 配置用文件，不用散落的命令行参数。运行时把实际生效的完整配置写进输出目录。
- 记录环境：驱动、SDK、固件、库版本。
- 有非确定性来源时，写明来源和开关，比较时两边设置一致。

**边界：** 区别于 **principle-caliber-on-every-number**（数字怎么报）。

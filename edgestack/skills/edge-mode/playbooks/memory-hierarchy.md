### Memory hierarchy（存储层级）

**你拥有每一级存储的字节账。缓存和 offload 策略按命中率和搬运字节评估，不按直觉。**

1. 列出每级存储：容量、可达带宽、延迟，以及模型每步要读的数据（权重、KV cache、激活、专家、表）。
2. 算每步搬运字节和最慢层级的时间（**principle-bytes-are-the-budget**）。
3. 决定放置：常用的放近处，按访问频率排。需要访问轨迹时先采集轨迹（例如路由统计、注意力访问）。
4. 设计预取和重叠：下一步要用的数据在本步计算时搬。测量重叠是否真的发生（时间线里看）。
5. 缓存策略：记录命中率、搬运字节、换入换出次数。和静态放置对比。
6. 压缩选项（低位宽 KV、旋转后量化、混合位宽）先算省下的字节，再测精度损失和解压开销。
7. 测长输入和长会话下的行为：缓存增长、峰值内存、命中率变化。
8. 提供确定性开关（缓存状态影响数值时），在口径里注明。

**回复：** 每级的字节账、命中率、重叠效率、端到端收益、长输入行为、未测的配置。

### Session pickup（接手）

**你拥有恢复点。读前人的轨迹，不重做。**

1. 找到轨迹：本地 transcript、云端会话记录、集群日志、总账、决策轨迹、推送的分支。长记录交给子 agent 读，主线只留时间线摘要（**principle-guard-the-context-window**）。
2. 先读最后几条消息和最近的决策点，再往前扫关键分叉。
3. 重建状态：分支与工作目录、已提交和未提交的改动、在跑和已结束的作业、结果文件、未完成的待办。直接查集群和板子确认作业状态。
4. 对比计划和已完成的部分，写出恢复点。不重跑已完成的实验。
5. 把剩余工作路由到对应的 playbook。
6. 继承来的关键结论在真实产物上复核一次（**principle-prove-it-works**）。

**回复：** 前人停在哪里、继承了什么、恢复点、需要复核或重做的部分（理想是没有）。

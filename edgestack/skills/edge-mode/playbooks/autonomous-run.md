### Autonomous run（自主长跑）

**你拥有退出条件。定义完成，然后驱动到完成，中途不停。**

1. 第一次迭代前写出可检查的谓词（指标达到某值、对拍全部通过、全部分段跑完）。
2. 选唤醒方式：有事件可等（作业完成、文件出现）就等事件，加一个长时间的兜底心跳。没有事件就按结果值得复查的间隔定时。
3. 每次迭代做证据支持的最小改动，对照谓词验证，前进就提交，没帮助就回退。
4. 中途发现的问题自己处理，单独提交。只把不可撤回的动作、真正的偏好决定、确实的死路交给人。
5. 每次迭代写一行决策轨迹（**show-me-your-work** skill）。
6. 谓词满足才停。平台期不是停止理由。不放宽谓词。

**回复：** 退出条件、迭代次数、完成了什么、回退了什么、谓词最终状态。

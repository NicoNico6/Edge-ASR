# 口径行

每张表、每个关键数字后面写一行口径。字段之间用「·」分隔，缺的字段写「未记录」，不省略。

```
口径：<数据集与切片> · <样本数> · <输入规格> · <设备与固件> · <时钟与功耗模式> · <精度与量化状态> · <预热与运行次数> · <代码版本>
```

例：

```
口径：测试集 v3 主切片 · 1200 条 · 16 kHz 单声道 ≤30 s · 某 SoC NPU SDK 2.1 · 性能模式实测 1.2 GHz · INT8 权重 FP16 激活 · 预热 20 次后 5 轮中位 · commit 1a2b3c4
```

需要时追加：评分口径（严格或宽松、归一化器）、是否开启守卫、是否开启确定性开关、是否含预处理与后处理。

不同口径的数字不放进同一列比较。必须并列时，在表注里写明差异。

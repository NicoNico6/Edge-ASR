# Converge

目标是用最少的轮次得到能改变决定的结论。每轮实验是一次购买信息，不是一次尝试。

## 认知状态文件

在实验目录维护 `STATE.md`，每轮更新（改写，不只追加）：

- **问题**：这批实验要回答的那一个问题，和它对应的决定。
- **当前最优**：配置、三轴数字、run_id。
- **已知**：每条一句结论，附证据（run_id、数字、样本量）和强度（单 seed、多 seed、显著）。
- **已排除**：方向、排除它的机制证据。
- **未知**：按「对决定的影响 × 不确定性」排序。
- **下一轮**：问什么，为什么是它。

新会话接手时先读这个文件。

## 轮次卡（运行前）

```
问题：
假设：
预测：<指标> 落在 <区间>，因为 <机制>
决策表：结果 < a → 做 X；a 到 b → 做 Y；> b → 做 Z
成本：<GPU 时 / 板时 / 墙钟>
中止判据：<第几步、什么信号出现就停>
最小规模：<能回答问题的最小数据量、步数、模型规模>
```

决策表每行动作相同，就不跑。能用已有结果回答，就不跑。

## 选实验

- 按「预期信息量 ÷ 成本」排序。信息量高的是：能区分两个主要假设的、结果最不确定的、影响最大决定的。
- 先小后大：短训练、小切片、小模型代理。用之前确认代理和全量的排序一致（在 3 到 5 个已知点上比较）。
- 一轮可以并行多个臂，但每个臂对应决策表里的一个分支，不并行无关的配置。
- 训练类实验看早期信号：前 5% 到 10% 步数的损失曲线、梯度范数、关键指标的趋势。设早停判据，明显劣于对照的臂提前停。

## 轮后提炼（运行后，下一轮之前）

```
现象：<带数字的观察>
和预测的差：<哪里对，哪里错>
机制假设：<最可能的解释>，备选：<另一个解释>
区分它们的最便宜实验：
认知更新：<STATE.md 里改了哪几条>
```

结果在噪声内就写「不可测量」，不写趋势。

## 收敛与转向规则

- 连续两轮认知状态没有实质变化：停止换配置。回到五问检查问题是否问对，或改变实验类型（换诊断实验、换分析方法、看样本而不是看均值）。
- 同一方向三轮仍未接近目标：写出阻止收敛的机制假设，向负责人报告并给出转向选项（换路线、换数据、换结构、接受当前点）。
- 判一个方向死刑要写机制，不写「试了不行」。
- 每轮结束看失败样本（抽 10 到 20 条），很多现象只在样本里看得到。
- 汇报时给结论和证据，不给轮次流水账。

## 输出

每轮：轮次卡、提炼、STATE.md 的变化。阶段结束：STATE.md 全文、总账行、下一步建议。

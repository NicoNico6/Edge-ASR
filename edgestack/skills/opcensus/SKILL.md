# Opcensus

## 步骤

1. 导出模型的算子清单：算子类型、输入输出形状、dtype、属性、出现次数、所在层。从导出的图（ONNX、TorchScript、编译器 IR）里取，不手抄。
2. 收集目标包络：官方支持列表（原文）、已知限制（硬件怪癖文件）、实测结果。每条带 SDK 或固件版本。
3. 逐条对照，每个算子归一类：直接支持、需改写（写出等价改写）、需回退到 CPU、不确定（需要实测）。
4. 不确定的写最小测试：单算子，边界形状，在板上和参考对拍。注意静默错误：结果错但不报错。
5. 汇总支持矩阵和改图清单，数清改写后的跨界次数和预计开销。

## 常见包络维度

形状上限与对齐（维度上限、行数倍数、通道对齐）、dtype（是否支持 fp16、int8、int16 累加、混合精度）、动态形状与控制流、内存放置（片上缓冲大小、DDR 访问方式）、同步与缓存一致性（是否需要手动刷新）、失败模式（报错、静默错算、回退）。

## 输出

支持矩阵（算子、次数、类别、证据）、改图清单、需要板上验证的项、包络表更新（新发现的约束带版本号写进硬件怪癖文件）。

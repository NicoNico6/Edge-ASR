# 给结论划范围

每个结论写明它依赖的条件（模型族、硬件、运行时、标定方法、数据集）和能否迁移。结构通常可以迁移，常数通常要重调。每份记录写自己的限度和未完成项；发现错误时回到原始记录，公开更正。

**为什么：** 在一块芯片上成立的结论换一块就可能失效。不划范围的结论会被误用到不成立的地方。没有限度说明的报告会被当成比实际更强的证据。

**做法：**
- 结论后加一句「可迁移」或「不可迁移」，说明原因。
- 报告末尾固定两节：「未完成」和「这份记录的限度」（样本量、单 seed、未在某硬件上验证等）。
- 发现之前的结论错了，在原记录上追加更正，写明改了什么、为什么，不删除原文。

**边界：** 区别于 **principle-caliber-on-every-number**（单个数字的口径）。

# 每个数字带口径

每个数字带口径：数据集与切片、样本数、输入规格（分辨率、序列长度、时长）、设备与固件、时钟与功耗模式、精度与量化状态、预热与运行次数、代码版本。口径不同的数字不放在一起比。

**为什么：** 同一个模型，换功耗模式、换是否用 CUDA Graph、换评分口径，数字可以差很多。不带口径的数字无法复核，也会被拿去和不可比的数字比较。

**做法：**
- 用 `references/caliber-block.md` 的格式写口径行，放在每张表后面。
- 评分口径不止一种时（严格与宽松、语料级与句级），都报，并写明主口径。
- 引用别人的数字，标明是原文还是转述，以及它的口径和你的口径差在哪里。
- 非独立的测试集（和训练集、调参集重叠）明确标出，不当泛化证据。

**边界：** 区别于 **principle-reproducible-by-config**（能不能重建）和 **principle-noise-floor-first**（数字的分辨率）。

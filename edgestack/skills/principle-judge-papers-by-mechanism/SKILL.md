# 按机制判断论文

判断一篇论文时问四件事：它的机制是什么（省了什么、改了什么分布），在什么条件下成立，证据有多强，在我们的条件下预计能买到多少。结论写成采用、先复现锚点、或忽略，并附预计收益。

**为什么：** 论文的数字是在它的条件下、和它选的基线比出来的。基线没调好、算力不匹配、只报最优 seed、只在大模型上验证的结果，搬到端侧小模型上常常不成立。没有判断力就会把论文当成待办清单。

**做法：**
- 用 **paper-judgment** skill 的清单。
- 先把机制写成一句话：「它通过 X 减少了 Y」。写不出来说明还没读懂。
- 查基线公平性：是否等算力、等数据、调过超参、多 seed、报方差。
- 查条件：模型规模、batch、硬件、任务、数据量，和我们差多远。
- 效应量和噪声比：提升是否超过它自己的方差，消融是否支持每个组件。
- 预测迁移：在我们的约束下，机制还成立吗？预计收益多少（推断）？
- 有代码就读代码，论文未写明的细节以代码为准（**principle-cite-precedent**）。

**边界：** 区别于 **principle-verify-the-inputs**，那条管复现和核实；这条管读的时候怎么判断值不值得复现。

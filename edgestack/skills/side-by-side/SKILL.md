# Side by side

## 规则

- 同一条输入、同一个种子、同一份产品设置。只有被比较的那个变量不同。
- 参考在前（原始输入、教师或上一版），候选按版本排在后面。
- 固定显示条件：深度和误差图用固定色标（取全序列分位数），音频统一响度，视频同帧率同分辨率。
- 按场景分区（例如情感、方言、长句、噪声、边缘结构），每区挑有代表性的和最差的样本。
- 自动指标放在一起但折叠，标「参考」。
- 页面写口径和数据来源，声明数字是实测还是估算。
- 留一个地方记录人的判断（谁、什么时候、哪些样本、结论），判断写进总账。

## 形式

可以是 HTML 页面（音频用内嵌或相对路径，点击播放，一次只播一段），视频四宫格，或图片网格。需要分享时发布为 Artifact。

## 输出

产物路径或链接、样本选择说明、人的判断记录。

# Parity

## 阶梯

浮点参考 → 低精度浮点 → 量化模拟 → 运行时量化 → 板上。每级只和上一级比。

## 步骤

1. 固定参考输入（几条，含一条最坏输入），固定预处理，两边用同一份输入文件。
2. 在每层或每个阶段的输出处 dump 张量，文件名带层名和阶段。
3. 比较：`python3 scripts/parity_diff.py <参考目录> <候选目录> [--cos-min 0.999]`，输出每个张量的 max abs、cosine、相关系数，以及第一个低于阈值的张量。
4. 第一个发散点之前都对齐，问题就在这一层。只换这一层的实现来确认。
5. 对不上时先怀疑观测：dump 的位置是否一致、数据布局（NCHW 与 NHWC）、dtype 转换、量化参数是否套对、探针本身是否改变了执行。
6. 量化模拟和板上量化的损伤要先对齐（同一批样本上比较），对不齐时不要基于模拟去训练或调参。

## 阈值

按阶段定，写明依据。浮点到低精度浮点通常要求 cosine 接近 1；量化后看端到端指标是否在噪声底内，逐层只用于定位。

## 输出

逐层对比表、第一个发散点、确认实验、结论（数值精度、实现错误、硬件行为）。硬件行为记进怪癖文件。

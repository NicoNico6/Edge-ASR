# 先预测再运行

运行之前写下：你预测的结果、每种可能的结果会让你做什么决定。如果所有结果都导向同一个决定，这个实验不跑。

**为什么：** 无意义的多轮实验大多有一个共同点：跑之前没想清楚结果会改变什么。没有预测，结果出来后只能「再试一个配置」；有预测，结果和预测的差距本身就是信息。

**做法：**
- 用 **converge** skill 的轮次卡：问题、假设、预测（带数值范围）、决策表（结果在 A 区间做什么，在 B 区间做什么）、成本、中止判据。
- 决策表里如果每一行的动作都一样，删掉这个实验，或者改成能区分动作的实验。
- 预测写数值范围，不写「应该会变好」。预测错了要记下来，它说明你对系统的理解哪里错了。
- 对候选实验按「预期信息量 ÷ 成本」排序，先跑最高的（**principle-cheapest-discriminating-experiment**）。

**边界：** 区别于 **principle-extract-the-phenomenon**，那条管跑完之后。

# 提炼现象再继续

每轮结束先写三句话再开下一轮：观察到什么现象（带数字），它和预测差在哪里，最可能的机制是什么。下一轮必须针对这个机制。没有新现象的连续两轮，停下来重新定问题，不再换配置。

**为什么：** agent 最常见的低效是看到结果不好就换一个超参再跑，结果攒了十几轮，没有一条结论。现象和机制才是可积累的东西，配置只是手段。

**做法：**
- 轮次结束写：现象、意外之处、机制假设、证据强度、对当前认知的更新、下一轮问什么。
- 维护一份「认知状态」文件：已知（带证据）、未知、当前最优、已排除的方向（**converge** skill）。每轮更新它，而不是只追加结果。
- 现象要具体：不是「蒸馏效果不好」，而是「蒸馏后 KL 降到 0.4 但 argmax 一致率下降，说明分布对齐了尾部而不是峰」。
- 连续两轮信息增量为零（认知状态没变化）：停，回到五问，或者向负责人报告并给出转向建议。
- 能用已有结果回答的问题，先分析已有结果，不开新实验。

**边界：** 区别于 **principle-falsified-paths-are-assets**（失败怎么记）和 **principle-predict-before-run**（跑之前）。

# Verify inputs

## 数据

- 来源地址或 repo id、版本或 commit。
- 分片命名与数量、字节数、条数或时长，下载后逐项核对。
- 许可：可否商用、是否禁止衍生、是否要求署名。受限数据不入库、不贴进对话、不上传公开位置。
- 划分：和现有训练集、测试集的重叠，按内容哈希或 ID 去重。
- 抽样人工查看几条，确认标注和描述一致。

## 对手方法或论文数字

- 论文的口径：数据集版本、评分方式、seed 数、硬件。
- 锚点复现：最快的数据集、重合的模型、默认超参，通过标准先定（例如原文数字正负 3 个点）。
- 管线无罪：先用同一模板、解析、评分复现论文的基线行。
- 论文未写明的细节逐条记录你的选择。复现不了时写清是哪个环节对不上。
- 对手的工程故障（崩溃、超时）剔除并说明，不算作方法本身的错误。

## 教师输出与伪标

模型与版本、解码设置、抽样核对质量、和真实标注分开标记。

## 引用

只用真实文献库导出的条目（Google Scholar、DBLP、出版方页面），不生成引用。转述别人的数字标「转述」。
